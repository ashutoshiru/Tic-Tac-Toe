# 🎮 Tic Tac Toe Game

A simple **Tic Tac Toe (X-O)** game built using **HTML, CSS, and JavaScript**.  
This project is beginner-friendly and helps understand basic DOM manipulation and game logic in JavaScript.

---

## 🧩 Features

- Two-player game (Player X vs Player O)
- Interactive UI
- Displays winner or draw result
- Restart / Reset game option
- Simple and clean design

---

## 🛠️ Technologies Used

- **HTML** – Structure of the game  
- **CSS** – Styling and layout  
- **JavaScript** – Game logic and interactivity
